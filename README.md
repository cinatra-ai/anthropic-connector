# Anthropic

Connect your Anthropic account so Cinatra agents can run on Claude. Once you bring your key, any agent pinned to a Claude model becomes runnable, and you can pick the default Claude variant the workspace falls back to when an agent does not name one.

## Capabilities

- Run Cinatra agents on Claude
- Choose the default Claude model used across the workspace
- Let Claude reach Cinatra's tools through native MCP or a function-tools fallback
- Cut token cost on long, repeated prompts with prompt caching
